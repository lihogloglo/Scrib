# MWScript function table (scripting-adapter.md "The `mw` runtime library").
# Written from the public function lists (UESP "Morrowind:Script Functions", Tribunal and
# Bloodmoon additions); signatures checked against the vanilla corpus (W1 real-install test).
#
# Extra trailing arguments the engine ignores are modelled as `num*` / `?` tails where the corpus
# uses them (AIFollow/AIEscort reset flags, StopCombat target, Face third value).
#
# Columns (whitespace separated):
#   name     canonical name; `|` adds aliases; `{$LIST}` or `{A,B}` expands to one row per item
#   args     comma separated; `-` = none. Kinds: id (record/object ID, bare or quoted), text
#            (string), num (numeric value), axis (X/Y/Z), any (string or value).
#            Suffix `?` = optional, `*` = zero or more (last only).
#   returns  void | int | float
#   family   groups functions for the M5/M7 status table (W2 coverage report)
#   ref      r = acts on a reference (implicit or `id->`); - = global function
#
# Lists:
