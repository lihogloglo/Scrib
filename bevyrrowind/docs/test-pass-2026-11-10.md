**Read the baseline with `perf.md` "Caveats on the S0 numbers" open.** The ones that change what a number means:

- **Views under `SkipRootViewRendering` under-report.** The lamp shadow-cache LRU leaves most cube faces unrendered
  each frame, and such a view still reports `items` and `bins` but near-zero `batch_sets` and `work_items`: lamp-face
  cost is understated, so do not read a low lamp-face number as "lamp faces are cheap".
- **Three `sun_view` depth views are labelled `cascade0` and summed into the real first cascade.** Precipitation
  occlusion, shelter and canopy all carry `LightEntity::Directional { cascade_index: 0 }`, so `views/cascade/count`
  reads 7 for a 4-cascade sun. Read cascade0 as a bundle of four. Shadow-cache capture views likewise appear as
  `lamp.face6`-`lamp.face11`, not as faces 0-5.
- **The batch-set counter is blind to instance batches until the slice now in flight lands.** `batch_set_count()` read
  only `self.batch_sets` (port audit A5), so a build without that fix reports **zero extra draws for all statics**. A
  **pre-S3b baseline is still a valid "before"** — nothing in the game spawns a `GpuBatchedMesh3d` yet, so there is
  nothing for it to miss — but a **post-S3b number taken on a build without the fix is not comparable with it**. The
  fix is on branch `static-scene/gs-slice-a` (commit `a80593c`) and not yet on `main`.
- **`views/main/batch_sets` sums all four phases** (opaque, alpha mask, two prepass), while the spec's budget row
  means one pass.
- **A per-label "mean" is a per-label sum** over every view sharing that label in the frame; divide by that label's
  `views_per_frame` for a per-view figure.
- **`work_items` is reserved, not surviving**, once statics exist: an instance batch reserves one work item and one
  output slot per capacity slot. Read it as cost, never as "visible statics".

One more, found 2026-11-09 and **not** in `perf.md`: `perf.md:53-54` ("Current levers and leads") still names our extra
sun views as `NoIndirectDrawing`/`PreprocessingOnly`. The code has since made them inherit the camera's flag, clamped
by `GpuPreprocessingSupport` (`sf_sky_bevy/src/sun_view.rs:230-231,254-255`), so that lead is stale and the statics'
hardware floor is adapter-wide, not per view.
