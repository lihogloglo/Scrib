## Standing facts
- Walk floor without the near ring is GPU-bound, 7.7 ms: DLSS 2.2, sky ~2.0 (probe + atmosphere LUTs re-run every frame), far 0.8, shadows 0.7 (2026-11-12). `--off sky` also drops DLSS: never read it as the sky cost.

- Ceiling: `--off statics` walk 7.21 ms vs 10.95 base (2026-11-12): statics (CPU) cost 3.7 ms walking, 2.0 standing; NPCs ~2.0 ms of the walk (`--off actors` 8.90).
- The walk is render-thread bound; standing Balmora is near GPU bound (timed GPU ~8.2 ms of 9.3-9.5). CPU fixes help the walk, not standing.
- Frame ~ slowest of main, render and GPU (pipelined); traced runs add ~2.3-2.7 ms of overhead, so traces rank costs and only untraced 3x A/Bs give ms.
- Halving mesh entities (precombine) did not move the frame; cost scales with bins/items x views (about 22 views on the walk: 1 main, 3 cascades, 18 lamp faces).
- `NoCpuCulling` on statics has failed twice (81 ms; then 113 stutters/min, p99 22 ms) and is opt-in only; the default path meets 11 ms standing and walking (9.3-10.9).
- DLSS SR costs ~2.2 ms GPU; sky/clouds/fog ~0.7-0.9 ms; sun cascades cost 4.8 ms standing and 7.7 ms walking when ungated (2026-10-19, before the shadow resets).
- A/B noise is +-0.2-0.4 ms and machine drift is real (the same old path read 10.71, 10.95 and 11.72 ms on the walk on 2026-11-11/12); only differences over ~0.5 ms count.
