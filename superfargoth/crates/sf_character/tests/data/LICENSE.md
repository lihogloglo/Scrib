# Test rigs (CC0 1.0)

Node hierarchies and skin joint lists extracted from Quaternius assets
(https://quaternius.com), licensed CC0 1.0 Universal
(https://creativecommons.org/publicdomain/zero/1.0/). Meshes, buffers and
animations were dropped; rest transforms are rounded to 1e-6.

- `quaternius_universal_rig.gltf`: the Universal rig (UE-style names, 65
  joints) of `Mannequin_F.glb` (Universal Base Characters), as mirrored at
  https://github.com/Dallolz/moorfall-assets (`characters/Mannequin_F.glb`).
- `quaternius_ual1_rig.gltf`: the rig (Rigify `DEF-` names) of the free
  Universal Animation Library 1, Godot export
  (`AnimationLibrary_Godot_Standard.gltf`), as mirrored at
  https://github.com/J-Ponzo/gltf-universal-animation-library.
- `quaternius_ual1_tpose.json`: the first rotation key of every joint in that
  file's `A_TPose` clip.
