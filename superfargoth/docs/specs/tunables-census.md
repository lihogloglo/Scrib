# Tunables census

Status: generated by `node tools/tunables-census.mjs` (spec `tunables.md`, slice T0, 2026-11-16). **Grep this file, never read it whole.** Every row is a
*candidate* found by name; the class is a first pass by rules, not a decision. A migration slice (tunables.md
"Migration") re-reads its system's rows, applies tunables.md "What stays a const", and fills provenance.

## How it is made

The generator is `tools/tunables-census.mjs` (Node ≥ 18, no dependencies; slice T0). Its header says what it scans
and excludes, and its classification rules are the table at its top. From the repo root:

```sh
node tools/tunables-census.mjs                    # regenerate "Generated tables" below (deterministic) + totals
node tools/tunables-census.mjs --check            # ratchet: fails if a crate's T count rises over tools/tunables-baseline.json
node tools/tunables-census.mjs --update-baseline  # after a migration slice lowered counts
node tools/tunables-census.mjs --json             # raw rows (file, line, name, type, value, class, system)
```

Everything above "Generated tables" is hand-written and kept on regeneration; everything from it on is rewritten.
A true constant the rules misclassify takes `// tunables: const (reason)` on its line or the line above (tunables.md
"What stays a `const`"). Cross-checks with plain ripgrep (the script's three sources):

```sh
rg -n -g '*.rs' -g '!*tests*' '^s*(pub(([a-z]+))?s+)?consts+[A-Z][A-Z0-9_]*s*:s*(bool|f32|f64|ud+|id+|usize|isize|Duration|Vec[234]|[f32;)' superfargoth/crates bevyrrowind/crates bevyrrowind/apps
rg -n -g '*.rs' 'impl Default for w+' superfargoth/crates bevyrrowind/crates bevyrrowind/apps     # then literal fields inside
rg -n -g '*.wesl' '^s*consts+[A-Z][A-Z0-9_]*' superfargoth/crates bevyrrowind/crates
rg -o -N -I 'BEVYRROWIND_[A-Z0-9_]+' -g '*.rs' bevyrrowind superfargoth | sort -u                 # env switches
```

**What it scans:** `.rs`, `.wesl` and `.wgsl` under `superfargoth/crates`, `bevyrrowind/crates`, `bevyrrowind/apps`
(so not `target/`, `sdk/`, `superfargoth/vendor/`, `superfargoth/plugins/`, `superfargoth/examples/`); skips
`tests/`, `examples/`, `benches/`, `vendor/` dirs, test files (`tests.rs`, `test_*.rs`, `*_tests.rs` ...),
`#[cfg(test)]` items (an inline `mod` block by braces, a single item, the file of an out-of-line `mod x;`). Rows:
(1) `const NAME: <number, bool, tuple, array, Duration, Vec>` ; (2) every literal field of an `impl Default for X`
(one per line, or inside a one-line `Self { .. }`), container defaults (`Vec::new()` ...) dropped; (3) WESL/WGSL
`const`. **Not scanned:** literals inline in expressions (`if masked > 0.5`), preset `match` arms and values built in
game code (hand-listed in "Hand-reviewed" below), `.ron`/`.toml` data (already data).

**Class rules (first pass, in order):** C if the file is a test scene or lab (`level/`, `*_lab.rs`, viewers); C if a
`Default` field is runtime state (`elapsed`, `timer`, `predicted_us` ...); C for sentinels/derived (`::MAX`, `::ALL`,
`size_of`, hex); C for units and formats (`UNITS_PER_*`, `CELL_UNITS`); C for layout, maths and ids (`VERSION`,
`EPS`, `BYTES`, `STRIDE`, `MASK`, `PI`, `FLAG_*`, `DEBUG_*`, `NO_*` ...); C when the value is an expression of other
consts; C for small `u` integers in shaders without a tuning word (enum codes); **T** when the name carries a tuning
word (distance, range, radius, fade, budget, LOD, cascade, shadow, hysteresis, threshold, frames, seconds, speed,
gain, bias, scale, max/min, pixels, count, size, ...) or is a field of a `*Settings/*Config/*Params/*Budget/*Lod...`
default; C for a `usize` under 64 without one (indices); a file with 8+ unsure plain integers is an id table (C);
else **?**; an opt-out comment makes it C. Expect noise both ways (`MAX_RAYS` is T but is also a GPU array bound: see
tunables.md "Capacities"; packed-parameter offsets such as `P_HEIGHT` in terrain `common.wesl` read as T).
